# ContactMerge+ Cleaner — 製品ドキュメント＆サポート

iPhone 向けアプリ **ContactMerge+ Cleaner** の公式公開製品ドキュメントおよびサポートガイドです。本リポジトリにはユーザー向けドキュメントのみが収録されており、アプリのソースコードを公開するリポジトリではありません。

ContactMerge+ Cleaner はお使いの端末内で連絡先を処理し、アドレス帳を開発者のサーバーへアップロードすることはありません。また、開発者によるクラウドバックアップサービスも提供していません。（iCloud や Google などの iOS／アカウント連絡先同期や、システム／端末のバックアップは、ご自身のアカウント設定および iOS の設定によって管理される別の仕組みです。）

## 4ステップのクイックスタート

1. **バックアップを作成し、連絡先へのアクセスを許可する**: 大規模な整理を行う前に独立した日付付きバックアップ（`.vcf` ファイルの書き出しは任意）を用意し、機種変更時のデータ移行や初回の同期が完了するまで待ってから、iOS の確認画面で連絡先へのアクセスを許可します。
2. **スキャンを実行する**: スキャンを実行して、iPhone 内の重複候補グループを検出します。
3. **プレビューを確認し、メインの連絡先を選び、Apple の「連絡先」アプリでメモを確認する**: 重複グループを1つ開いて統合プレビュー（`Merge Preview`）の内容を確かめ、ベースとして残すメインの連絡先を選択します。あわせて Apple の**連絡先**（Contacts）アプリを開き、保存しておきたいメモ（Notes）がないか確認します。
4. **再確認してから慎重に確定する**: Apple の**連絡先**アプリへ切り替えて連絡先を閲覧・編集した場合は、ContactMerge+ Cleaner に戻ってから現在の重複候補とプレビューを改めて確認してください。カードが確実に同一人物のものであり、必要な項目がプレビューに保持されている場合のみ統合を確定します。

## 主な安全上の注意点と制限

- **`Ready to merge` と `Needs review` の違い**:
  - `Ready to merge`（統合準備完了）は、グループ内のすべての連絡先ペアが、強い根拠に基づく厳格な一致チェックを通過したことを意味します。それでも、名前や電話番号が同じというだけでは同一人物とは限らないため、確定前に必ずプレビューを確認してください。
  - `Needs review`（要確認）は、家族共用の電話番号、名前の表記ゆれ・相違、誕生日の不一致、部分的な一致など、根拠が弱いまたは矛盾していることを示します。これはエラーではなく安全上の保護措置です。`Needs review` のグループは1グループずつ手動で確認し、別人のカードは絶対に統合しないでください。
- **統合前に Apple の「連絡先」アプリでメモを確認・保存する**:
  - メイン以外の連絡先（統合される側のサブカード）にあるメモ（Notes）は、統合時に**読み取りもコピーもされず**、後から復元することもできません。
  - ContactMerge+ Cleaner はメモ欄を読み取ることができないため、統合プレビューにメモが表示されていなくても「メモが入っていない」と判断しないでください。統合前に必ず Apple の**連絡先**アプリで直接確認して重要なメモをコピーし、外部で連絡先を閲覧・編集したあとは ContactMerge+ Cleaner に戻って現在の重複候補とプレビューを再確認してから確定してください（開いている画面が自動更新されるとは限りません）。
- **直前の取り消しと端末内の復元機能**:
  - `Undo Last Contact Merge`（直前の連絡先統合を取り消す）は、直前に行った1件の統合のみを対象とします（確認済みの画面上の位置やバージョンに関する注意点は、[バックアップ、取り消し、復元履歴](../ja/recovery.md)をご参照ください）。
  - `Recovery History`（復元履歴）はアプリが端末内に保存する復元記録（ジャーナル）で、**統合記録を最大3件、削除記録を最大3件**、**端末内で約30日間**保持します（アプリ内での正確な移動経路は本ドキュメントでは未確認です。詳しくは[バックアップ、取り消し、復元履歴](../ja/recovery.md)をご覧ください）。
  - **システム全体の完全な復元ではありません**: メイン以外のカードにあったメモは復元できず、元のシステム識別子やリンクも元に戻らない場合があります。開発者によるクラウドバックアップサービスはありません（ご自身の iCloud／Google 同期や iOS システムバックアップとは別の仕組みであるため、統合結果が同期先アカウントへ反映される場合があります）。安全上の慎重な注意点として、統合後の連絡先編集、アプリのアンインストール、または端末の紛失・機種変更後の復元は保証されません。
- **独立したバックアップとアカウントの安全管理**: `.vcf` ファイルの書き出しは任意ですが、初回の整理を行う前に、実際に連絡先が保存されているアカウントを対象とした独立した日付付きバックアップを作成しておくことをおすすめします（アカウント同期は独立したバックアップの代わりにはなりません）。トラブル対処として元の連絡先を削除したり、`"Delete from My iPhone"`（iPhoneから削除）をタップしたり、アカウント同期のオフ／オン切り替えやアカウントの削除を行ったりしないでください。

## Free（無料版）と Pro の違い

- **Free**: 連絡先のスキャン、検出されたすべての重複候補グループの閲覧、および1回につき1グループずつの統合（グループ内の連絡先は最大3件まで）が可能です。複数グループの一括統合は含まれません。
- **Pro**: App Store での買い切り（1回払い）による機能解放で、サブスクリプション（定期購読）ではありません。地域ごとの価格は Apple によって直接表示されます。4件以上（3件超）の連絡先を含むグループの統合と、確認後の `Ready to merge` グループの一括統合が利用可能になります（`Needs review` グループは常に1グループずつの手動確認となります）。
- **購入の復元と請求・返金**: 購入時と同じ Apple Account での既存の Pro 購入の復元方法や、Apple の返金手続き（[reportaproblem.apple.com（英語）](https://reportaproblem.apple.com) を通じて Apple が管理し、返金の可否は保証されません）については、[よくある質問（FAQ）](../ja/faq.md#q16)をご確認いただくか、[公式サポート（英語）](https://contactmerge.app/support)までお問い合わせください。
